# Code of Conduct

VRX follows the [Contributor Covenant][cc], version 2.1. The full text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

To report unacceptable behavior, contact the maintainer,
[@Imperix1155](https://github.com/Imperix1155), on GitHub. If the details
shouldn't be public, open a short issue asking for a private contact without
including them. Every report is reviewed promptly and fairly.

[cc]: https://www.contributor-covenant.org/
